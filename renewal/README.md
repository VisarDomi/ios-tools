# Reader Extensions

One iOS containing app that has several independent Safari Web Extensions. This repository
owns **packaging and deployment**, not reader/provider/storage logic.

[gallery-reader](https://github.com/VisarDomi/gallery-reader)
[manga-reader](https://github.com/VisarDomi/manga-reader)
[km-explorer](https://github.com/VisarDomi/km-explorer)
[stream-viewer](https://github.com/VisarDomi/stream-viewer)

Each source repo owns its manifest, extension entry, runtime and behavior tests.
